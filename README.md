One sentence explaining the modern internet to a traveler from 1800. A single original sentence of 156 characters, built only from images a person of that year could already picture — a road, a post office, a library, a market, a fireside — so the stranger grasps what the internet is and what it does in one breath.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (or to `$ENTRY_OUTPUT` when set). The run is deterministic: the same 156 characters every time.

## The sentence

> Picture one road of light joining every library, post office, and market on earth, so any letter, book, or friend's face can reach your fireside in a blink.
